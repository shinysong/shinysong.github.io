# shinysong.github.io

개인 연구 블로그. Jekyll과 Chirpy 테마로 빌드하며 GitHub Actions가 `main` 브랜치 변경을 GitHub Pages에 배포합니다.

## 로컬 미리보기

Ruby 3.4와 Bundler가 필요합니다.

```bash
bundle install
bundle exec jekyll serve
```

글은 `_posts/`에, 그림과 출처 기록은 `assets/images/` 아래에 둡니다. 원문 그림의 라이선스와 출처는 각 글 및 해당 폴더의 `provenance.json`을 확인하세요.
